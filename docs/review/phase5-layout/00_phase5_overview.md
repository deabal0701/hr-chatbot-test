# Phase 5. 레이아웃 컴포넌트 - 화면 뼈대는 어떻게 구성되는가?

## 이 Phase에서 배우는 것

Phase 1~4에서 앱 시작, 라우팅, 상태 관리, API 통신을 이해했습니다.
이제 이 모든 것이 **화면에 어떻게 배치되는지** — 레이아웃 컴포넌트를 살펴봅니다.

## 비유로 이해하기

레이아웃 컴포넌트는 **건물의 뼈대(골조)**와 같습니다:

```
[건물 골조]                         [레이아웃 컴포넌트]

기둥 + 보 → 층별 공간 확보          AdminLayout → 관리자 화면 골조
벽 + 문 → 각 방 구분               UserChatLayout → 사용자 화면 골조
                                   AppHeader → 천장 (상단 바)
인테리어 → 방 안 꾸미기             AppSidebar → 복도 (메뉴)
(가구 = 각 View 컴포넌트)          router-view → 방 (실제 내용)
```

## 두 가지 레이아웃

이 앱은 **관리자 화면**과 **사용자 채팅 화면**, 완전히 다른 2개의 레이아웃을 가집니다:

```
[관리자 화면 - AdminLayout]          [사용자 화면 - UserChatLayout]
┌──────────────────────────┐        ┌──────────────────────────┐
│ AppSidebar │  AppHeader   │        │ UserChat │   Desktop     │
│            │──────────────│        │ Sidebar  │   Header      │
│  ☰ 메뉴    │              │        │          │───────────────│
│  대시보드   │              │        │ 새 채팅   │               │
│  사용자     │  router-view │        │ 이력 검색 │  UserChatView │
│  역할      │  (CRUD 화면)  │        │ 대화 목록 │  (채팅 화면)   │
│  문서      │              │        │          │               │
│  설정      │              │        │ 사용자   │               │
│ [v2.0.0]   │              │        │  정보    │               │
└──────────────────────────┘        └──────────────────────────┘

특징: 좌측 메뉴 + 상단 헤더           특징: ChatGPT 스타일 사이드바
      다양한 CRUD 페이지 전환               대화 중심 인터페이스
```

## 파일 구조

```
frontend/src/
├── views/admin/
│   └── AdminLayout.vue           ← ⭐ 관리자 레이아웃 (골조)
├── components/layout/
│   ├── AppHeader.vue             ← ⭐ 관리자 헤더 (상단 바)
│   └── AppSidebar.vue            ← ⭐ 관리자 사이드바 (메뉴)
└── components/user/
    ├── UserChatLayout.vue        ← ⭐ 사용자 채팅 레이아웃
    └── UserChatSidebar.vue       ← ⭐ 사용자 채팅 사이드바
```

## 리뷰 시 스스로 답해볼 질문

1. 관리자 화면과 사용자 화면은 어떻게 다른 레이아웃을 사용하는가?
2. 사이드바 메뉴는 어디서 데이터를 가져오는가? (하드코딩? 서버?)
3. 반응형 디자인은 어떻게 처리하는가? (데스크탑 vs 모바일)
4. 다크모드 전환 시 레이아웃 색상은 어떻게 바뀌는가?
5. 페이지 제목은 어디서 정해지는가?
