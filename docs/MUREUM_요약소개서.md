# MUREUM 요약 소개서

> **"말로 물어보면, 데이터가 답합니다"**

---

## MUREUM이란?

대화창에 질문만 입력하면, AI가 **데이터베이스 조회 + 문서 검색 + 차트 시각화 + 대시보드 저장**까지 한 번에 처리하는 기업용 AI 어시스턴트입니다.

---

## 핵심 기능

### 1. 말로 데이터 조회
- "부서별 매출 보여줘" → AI가 자동으로 DB에서 조회하여 표로 표시
- "그 중에서 영업부만 보여줘" → **이전 대화를 기억**하는 연속 질문 가능
- 오류 발생 시 **자동으로 감지하고 수정**하여 재조회

### 2. 사내 문서 지능 검색
- 정책서, 매뉴얼, FAQ 등을 **질문 의미를 파악**하여 검색
- 정확한 키워드 없이도 **비슷한 의미로 검색** 가능
- 답변과 함께 **출처 문서와 위치**를 표시

### 3. 복합 질문 자동 해결
- "입사자 수는? 재택근무 정책은?" → AI가 **데이터 조회 + 문서 검색을 자동 조합**
- 사용자가 방법을 지정할 필요 없이 AI가 **스스로 판단**

### 4. 즉시 차트 시각화
- 조회 결과를 **대화창 안에서 바로 차트로 변환**
- 막대 / 꺾은선 / 원형 / 산점도 / 가로 막대 등 **5종 차트** 지원
- 데이터에 맞는 차트 유형 **자동 추천**, 상위 N건 필터, 6종 컬러 테마

### 5. 나만의 대시보드
- 자주 보는 차트를 **위젯으로 저장** → 나만의 대시보드 구성
- 대시보드 접근 시 **최신 데이터로 자동 갱신**
- 관리자용 **운영 현황판** 별도 제공 (KPI, 사용량 추이, 실시간 모니터링)

### 6. 실시간 진행 표시
- AI 처리 과정을 **단계별로 실시간 표시** (✓ 분석 완료 → ✓ 조회 완료 → ● 답변 생성 중)

## 적용 가능 산업

DB와 문서만 교체하면 **어떤 업종에든 즉시 적용** 가능합니다.

| 산업 | 활용 예시 |
|------|-----------|
| **제조** | "A라인 불량률 추이 보여줘" → 차트 → 일일 모니터링 대시보드 |
| **금융** | "지점별 실적 비교해줘" → Top-10 막대 차트 |
| **유통** | "카테고리별 매출 현황" → 도넛 차트 → 주간 보고용 |
| **의료** | "진료과별 환자 수 추이" → 꺾은선 차트 → 월간 리포트 |
| **물류** | "거래처별 리드타임 비교" → 가로 막대 → 공급망 대시보드 |
| **교육** | "학과별 학점 분포" → 원형 차트 → 학사 대시보드 |
| **공공** | "유형별 민원 현황" → 추이 차트 → 실시간 모니터링 |

## 기술 특장점

- **멀티 AI 모델**: OpenAI, Anthropic, Google 등 관리 화면에서 즉시 전환
- **멀티 DB**: PostgreSQL, Oracle 등 기존 업무 시스템과 바로 연결
- **설정 즉시 반영**: 서버 재시작 없이 관리 화면에서 실시간 변경
- **반응형 디자인**: PC, 태블릿, 모바일 + 다크 모드 지원
- **Excel 내보내기**: 조회 결과를 Excel로 바로 다운로드
- **오류 자동 복구**: 조회 실패 시 원인 분석 후 자동 재시도
