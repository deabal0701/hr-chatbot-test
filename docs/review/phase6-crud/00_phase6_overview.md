# Phase 6. 화면 컴포넌트 — 실제 화면은 어떻게 만들어지는가?

## 이 Phase에서 배우는 것

Phase 5에서 레이아웃(골조)을 이해했습니다.
이제 그 골조 안에 들어가는 **실제 화면**(View 컴포넌트)을 살펴봅니다.

## 비유로 이해하기

레이아웃이 "건물 골조"라면, View 컴포넌트는 **각 방의 인테리어**입니다:

```
[건물 골조 = AdminLayout]        [인테리어 = View 컴포넌트]

┌─────────┐                      ┌─────────┐
│  벽, 문  │ ← 골조(고정)         │  가구    │ ← 인테리어(교체 가능)
│  천장    │                      │  조명    │
│  바닥    │                      │  커튼    │
└─────────┘                      └─────────┘

레이아웃 (Phase 5)               화면 컴포넌트 (Phase 6)
├─ AppSidebar (항상 표시)         ├─ LoginView (로그인)
├─ AppHeader (항상 표시)          ├─ UsersView (사용자 관리)
└─ <router-view />               ├─ RolesView (역할 관리)
     ↑ 여기에 교체됨!              ├─ DocumentsView (문서 관리)
                                  └─ DashboardView (대시보드)
```

## 이 앱의 화면 유형

크게 3가지 유형으로 분류됩니다:

```
┌────────────────────────────────────────────────────────────┐
│                     화면 유형 분류                           │
├──────────────┬────────────────────┬────────────────────────┤
│  ① 인증 화면  │  ② CRUD 관리 화면   │  ③ 대시보드 화면        │
│              │                    │                        │
│  LoginView   │  UsersView         │  DashboardView         │
│  (로그인)     │  RolesView         │  (KPI + 차트 +          │
│              │  TenantsView       │   최근활동 + 시스템현황)  │
│  특징:       │  MenusView         │                        │
│  · 레이아웃X  │  DocumentsView     │  특징:                  │
│  · 폼 검증   │  CodesView         │  · 자식 컴포넌트 조합    │
│  · Store 연동 │  SettingsView      │  · 자동 새로고침        │
│              │  HistoryView       │  · 기간 필터            │
│              │                    │  · 반응형 그리드        │
│              │  특징:              │                        │
│              │  · 테이블+필터+페이징│                        │
│              │  · 다이얼로그 폼    │                        │
│              │  · CRUD API 연동   │                        │
│              │  · 권한 기반 UI     │                        │
└──────────────┴────────────────────┴────────────────────────┘
```

## CRUD 화면의 공통 패턴

모든 관리 화면은 같은 구조를 반복합니다:

```
CRUD 화면 = 레고 블록 조합

① 페이지 헤더
┌──────────────────────────────────────────┐
│  사용자 관리                    [새 사용자] │
│  사용자 계정을 생성, 수정, 삭제...          │
└──────────────────────────────────────────┘

② 필터 + 툴바
┌──────────────────────────────────────────┐
│  [🔍 검색] [테넌트 ▼] [상태 ▼] [초기화]    │
└──────────────────────────────────────────┘

③ 데이터 테이블
┌──────────────────────────────────────────┐
│  ID │ 이름  │ 역할   │ 상태  │ 동작       │
│─────┼───────┼────────┼───────┼───────────│
│  1  │ 관리자 │ GLOBAL │ 활성  │ [수정][삭제]│
│  2  │ 김철수 │ TENANT │ 활성  │ [수정][삭제]│
└──────────────────────────────────────────┘

④ 페이지네이션
┌──────────────────────────────────────────┐
│  총 25건  10건/페이지  ◀ 1 2 3 ▶  이동    │
└──────────────────────────────────────────┘

⑤ 생성/수정 다이얼로그 (숨겨져 있다가 표시)
┌──────────────────────────────────────────┐
│  새 사용자 추가                      [X]  │
│  ┌────────────────────────────────────┐  │
│  │  로그인ID: [________]              │  │
│  │  이름:     [________]              │  │
│  │  역할:     [▼ 선택  ]              │  │
│  └────────────────────────────────────┘  │
│                        [취소] [생성]      │
└──────────────────────────────────────────┘
```

## 파일 구조

```
frontend/src/views/
├── LoginView.vue                 ← ⭐ ① 로그인 (인증 화면)
└── admin/
    ├── UsersView.vue             ← ⭐ ② CRUD 대표 (사용자 관리)
    ├── RolesView.vue             ← ⭐ ② CRUD 변형 (역할 관리)
    ├── DocumentsView.vue         ← ⭐ ② CRUD + Store 연동 (문서 관리)
    ├── DashboardView.vue         ← ⭐ ③ 대시보드 (자식 컴포넌트 조합)
    ├── TenantsView.vue           │
    ├── MenusView.vue             │  구조가 유사한 나머지 CRUD 화면들
    ├── CodesView.vue             │  (패턴을 익히면 쉽게 이해 가능)
    ├── SettingsView.vue          │
    ├── HistoryView.vue           │
    └── ChatView.vue              ← Phase 7에서 다룸
```

## Element Plus 핵심 컴포넌트

이 Phase에서 자주 등장하는 Element Plus 컴포넌트:

```
화면 구성 요소:
┌─────────────────┬──────────────────────────────────┐
│ 컴포넌트         │ 역할                              │
├─────────────────┼──────────────────────────────────┤
│ el-form         │ 폼 컨테이너 (검증 규칙 관리)        │
│ el-form-item    │ 폼 필드 하나 (라벨 + 입력 + 에러)   │
│ el-input        │ 텍스트 입력                        │
│ el-select       │ 드롭다운 선택                      │
│ el-table        │ 데이터 테이블 (정렬, 필터)          │
│ el-table-column │ 테이블 열 정의                     │
│ el-pagination   │ 페이지네이션                       │
│ el-dialog       │ 모달 다이얼로그                    │
│ el-button       │ 버튼                              │
│ el-tag          │ 상태 뱃지 (success/danger/info)    │
│ el-tabs         │ 탭 패널 (다중 폼 구성)             │
│ el-message      │ 토스트 알림 (성공/실패)             │
│ el-message-box  │ 확인 다이얼로그 (삭제 확인 등)      │
│ el-tree-select  │ 트리 구조 드롭다운 (부서 선택 등)    │
└─────────────────┴──────────────────────────────────┘
```
