# MUREUM NL2SQL — 말로 물어보면 데이터가 답합니다

> 자연어(Natural Language)를 SQL로 자동 변환하여 데이터베이스를 조회합니다.
> SQL을 몰라도, 프로그래밍을 몰라도 누구나 데이터를 활용할 수 있습니다.

---

## NL2SQL이란?

```
사용자: "부서별 직원 수 알려줘"
                ↓  AI가 자동 변환
       SELECT department, COUNT(*) FROM employee GROUP BY department
                ↓  실행 결과
       [표] 영업부 25명, 개발팀 32명, 마케팅부 18명...
                ↓  자연어 답변
AI: "전체 75명이며, 개발팀이 32명으로 가장 많습니다."
```

**사용자는 질문만 하면 됩니다.** SQL 변환 → 실행 → 결과 해석까지 AI가 자동 처리합니다.

---

## 처리 흐름 (4단계)

```
① 의도 분석     사용자 질문을 분석하고 이전 대화 맥락을 반영하여 질문 보완
      ↓
② 스키마 탐색   관련 테이블·컬럼을 자동 선택 + 유사 SQL 예제 검색
      ↓
③ SQL 생성      AI가 SQL 생성 → 보안 검증 → 실행 (오류 시 자동 수정·재실행)
      ↓
④ 답변 생성     실행 결과를 자연어로 변환 (개인정보는 자동 마스킹)
```

---

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **자연어 질의** | 일상 언어로 질문하면 AI가 SQL로 변환하여 즉시 조회 |
| **연속 대화** | 이전 질문을 기억하여 "그 중에서 개발팀만"처럼 추가 질문 가능 |
| **자동 오류 복구** | SQL 오류 시 원인을 분석하고 자동으로 수정하여 재실행 |
| **개인정보 보호** | 주민번호·전화번호 등 AI에게 전달되기 전 자동 마스킹 |
| **보안 통제** | 조회(SELECT)만 허용, 수정·삭제 명령은 원천 차단 |
| **실시간 진행 표시** | 의도 분석 → SQL 생성 → 실행 → 답변 각 단계를 실시간 표시 |
