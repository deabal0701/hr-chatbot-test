# 테이블 명세서 (Table Specification)

> 이 문서는 RAG 및 NL2SQL 챗봇 시스템(Hermes DB)의 테이블 명세서입니다.
> Excel에 붙여넣기 위해 탭으로 구분된 형식을 사용합니다.

---

## 1. tb_app_settings (애플리케이션 설정)

**테이블 설명**: 시스템 전체 설정값을 관리하는 테이블. LLM, RAG, NL2SQL, 임베딩 등 각 모듈의 설정을 카테고리별로 저장하며, 실시간 설정 변경을 지원합니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| tb_app_settings | id | bigserial | NOT NULL | - | PK | 설정 고유 ID (자동 증가) |
| tb_app_settings | category | varchar(50) | NOT NULL | - | UK | 설정 카테고리 (openai, llm, rag, nl2sql, agent 등) |
| tb_app_settings | key | varchar(100) | NOT NULL | - | UK | 설정 키 (api_key, model, top_k 등) |
| tb_app_settings | value | text | NOT NULL | - | - | 설정 값 |
| tb_app_settings | value_type | varchar(20) | NULL | 'string' | - | 값 타입 (string, int, float, bool, text) |
| tb_app_settings | description | text | NULL | - | - | 설정 설명 |
| tb_app_settings | is_secret | bool | NULL | false | - | 비밀 정보 여부 (true면 마스킹 표시) |
| tb_app_settings | created_at | timestamptz | NULL | now() | - | 생성 일시 |
| tb_app_settings | updated_at | timestamptz | NULL | now() | - | 수정 일시 |

**제약조건**:
- PRIMARY KEY: id
- UNIQUE: (category, key) - 카테고리와 키 조합은 유일해야 함

**인덱스**:
- idx_tb_app_settings_category: category 컬럼 인덱스

---

## 2. tb_code (공통코드 마스터)

**테이블 설명**: 시스템 전체에서 사용하는 공통코드를 관리하는 테이블. 문서유형, 언어, 상태코드 등 표준화된 코드값을 그룹별로 저장합니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| tb_code | code_id | bigserial | NOT NULL | - | PK | 코드 고유 ID (자동 증가) |
| tb_code | code_group | varchar(50) | NOT NULL | - | UK | 코드 그룹 (DOC_TYPE, LANGUAGE 등) |
| tb_code | code_value | varchar(100) | NOT NULL | - | UK | 코드 값 (policy, faq, ko, en 등) |
| tb_code | code_name | varchar(200) | NOT NULL | - | - | 코드 표시명 (정책, FAQ, 한국어, 영어 등) |
| tb_code | description | text | NULL | - | - | 코드 설명 |
| tb_code | metadata | jsonb | NULL | - | - | 추가 메타데이터 (JSON 형식) |
| tb_code | sort_order | int4 | NULL | 0 | - | 정렬 순서 |
| tb_code | is_active | bool | NULL | true | - | 활성화 여부 |
| tb_code | is_system | bool | NULL | false | - | 시스템 코드 여부 (true면 삭제/수정 제한) |
| tb_code | created_at | timestamptz | NULL | now() | - | 생성 일시 |
| tb_code | updated_at | timestamptz | NULL | now() | - | 수정 일시 |

**제약조건**:
- PRIMARY KEY: code_id
- UNIQUE: (code_group, code_value) - 그룹 내 코드값은 유일해야 함

**인덱스**:
- idx_tb_code_group: code_group 컬럼 인덱스
- idx_tb_code_active: is_active 컬럼 인덱스
- idx_tb_code_group_active: (code_group, is_active) 복합 인덱스

## 3. query_log (쿼리 로그)

**테이블 설명**: 사용자의 모든 질의 요청을 기록하는 로그 테이블. RAG, NL2SQL, Agent 등 모든 검색 유형의 기본 로그를 저장하며, 성능 분석 및 사용 통계에 활용됩니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| query_log | id | bigserial | NOT NULL | - | PK | 로그 고유 ID (자동 증가) |
| query_log | user_id | text | NULL | - | - | 사용자 ID (향후 인증 연동) |
| query_log | query_text | text | NOT NULL | - | - | 사용자 질의 원문 |
| query_log | query_type | text | NULL | - | - | 질의 유형 (rag, nl2sql, agent, auto) |
| query_log | intent | text | NULL | - | - | 분석된 질의 의도 |
| query_log | filters | jsonb | NULL | - | - | 적용된 필터 조건 (JSON) |
| query_log | response_time_ms | int4 | NULL | - | - | 응답 시간 (밀리초) |
| query_log | success | bool | NULL | true | - | 성공 여부 |
| query_log | error_message | text | NULL | - | - | 에러 메시지 (실패 시) |
| query_log | created_at | timestamptz | NULL | now() | - | 생성 일시 |

**제약조건**:
- PRIMARY KEY: id

**인덱스**:
- idx_query_log_created: created_at DESC (최신순 조회)
- idx_query_log_type: query_type 컬럼 인덱스
- idx_query_log_user: user_id 컬럼 인덱스

## 4. tb_docs (HR 문서)

**테이블 설명**: RAG 시스템의 핵심 테이블로, 기업 문서와 벡터 임베딩을 저장합니다. pgvector 확장을 사용하여 1536차원 벡터를 저장하고, 문서 청킹(분할) 정보도 관리합니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| tb_docs | id | bigserial | NOT NULL | - | PK | 문서 고유 ID (자동 증가) |
| tb_docs | title | text | NOT NULL | - | - | 문서 제목 |
| tb_docs | doc_type | text | NOT NULL | - | - | 문서 유형 (policy, faq, guideline 등) |
| tb_docs | language | text | NULL | 'ko' | - | 문서 언어 (ko, en) |
| tb_docs | content | text | NOT NULL | - | - | 문서 본문 내용 |
| tb_docs | metadata | jsonb | NULL | - | - | 추가 메타데이터 (카테고리, 태그 등) |
| tb_docs | embedding | vector(1536) | NULL | - | - | 텍스트 임베딩 벡터 (OpenAI 1536차원) |
| tb_docs | embedding_model | text | NULL | 'text-embedding-3-small' | - | 사용된 임베딩 모델명 |
| tb_docs | indexed | bool | NULL | false | - | 임베딩 완료 여부 |
| tb_docs | embedded_at | timestamptz | NULL | - | - | 임베딩 생성 일시 |
| tb_docs | chunk_index | int4 | NULL | 0 | - | 청크 인덱스 (0부터 시작) |
| tb_docs | total_chunks | int4 | NULL | 1 | - | 전체 청크 수 |
| tb_docs | parent_doc_id | int8 | NULL | - | FK | 부모 문서 ID (청크인 경우) |
| tb_docs | source_type | text | NULL | 'ui_input' | - | 소스 유형 (ui_input, file_upload, api) |
| tb_docs | source_file | text | NULL | - | - | 원본 파일명 (파일 업로드 시) |
| tb_docs | content_hash | text | NULL | - | - | 내용 해시 (중복 검사용) |
| tb_docs | created_at | timestamptz | NULL | now() | - | 생성 일시 |
| tb_docs | updated_at | timestamptz | NULL | now() | - | 수정 일시 |

**제약조건**:
- PRIMARY KEY: id
- FOREIGN KEY: parent_doc_id → tb_docs(id) ON DELETE CASCADE

**인덱스**:
- idx_tb_docs_embedding: embedding 컬럼 (IVFFlat, lists=100) - 벡터 유사도 검색
- idx_tb_docs_doc_type: doc_type 컬럼 인덱스
- idx_tb_docs_language: language 컬럼 인덱스
- idx_tb_docs_indexed: indexed 컬럼 인덱스
- idx_tb_docs_source_type: source_type 컬럼 인덱스
- idx_tb_docs_parent_doc: parent_doc_id 컬럼 인덱스
- idx_tb_docs_content_hash: content_hash 컬럼 인덱스
- idx_tb_docs_metadata: metadata 컬럼 (GIN 인덱스)
- idx_tb_docs_created_at: created_at DESC 인덱스

## 5. rag_search_log (RAG 검색 로그)

**테이블 설명**: RAG 검색의 상세 로그를 저장하는 테이블. query_log와 연결되어 검색된 문서, 사용된 LLM 모델, 토큰 수 등 RAG 특화 정보를 기록합니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| rag_search_log | id | bigserial | NOT NULL | - | PK | 로그 고유 ID (자동 증가) |
| rag_search_log | query_log_id | int8 | NULL | - | FK | 연결된 쿼리 로그 ID |
| rag_search_log | top_k | int4 | NULL | - | - | 검색된 상위 문서 수 |
| rag_search_log | retrieved_docs | jsonb | NULL | - | - | 검색된 문서 목록 (ID, 점수, 제목 등) |
| rag_search_log | llm_model | text | NULL | - | - | 사용된 LLM 모델명 |
| rag_search_log | llm_tokens | int4 | NULL | - | - | 사용된 토큰 수 |
| rag_search_log | created_at | timestamptz | NULL | now() | - | 생성 일시 |

**제약조건**:
- PRIMARY KEY: id
- FOREIGN KEY: query_log_id → query_log(id) ON DELETE CASCADE

**인덱스**:
- idx_rag_log_query: query_log_id 컬럼 인덱스

---

## 6. sql_execution_log (SQL 실행 로그)

**테이블 설명**: NL2SQL 시스템의 SQL 실행 상세 로그를 저장하는 테이블. 생성된 SQL, 실행된 SQL, 결과 행 수, 실행 시간 등을 기록하여 성능 분석 및 디버깅에 활용됩니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| sql_execution_log | id | bigserial | NOT NULL | - | PK | 로그 고유 ID (자동 증가) |
| sql_execution_log | query_log_id | int8 | NULL | - | FK | 연결된 쿼리 로그 ID |
| sql_execution_log | generated_sql | text | NOT NULL | - | - | LLM이 생성한 원본 SQL |
| sql_execution_log | executed_sql | text | NULL | - | - | 실제 실행된 SQL (보안 처리 후) |
| sql_execution_log | row_count | int4 | NULL | - | - | 반환된 행 수 |
| sql_execution_log | execution_time_ms | int4 | NULL | - | - | SQL 실행 시간 (밀리초) |
| sql_execution_log | success | bool | NULL | true | - | 실행 성공 여부 |
| sql_execution_log | error_message | text | NULL | - | - | 에러 메시지 (실패 시) |
| sql_execution_log | created_at | timestamptz | NULL | now() | - | 생성 일시 |

**제약조건**:
- PRIMARY KEY: id
- FOREIGN KEY: query_log_id → query_log(id) ON DELETE CASCADE

**인덱스**:
- idx_sql_log_query: query_log_id 컬럼 인덱스
- idx_sql_log_created: created_at DESC 인덱스

## 7. tb_prompt_history (프롬프트 변경 이력)

**테이블 설명**: 시스템 프롬프트 변경 이력을 추적하는 테이블. 프롬프트 변경 전/후 값을 저장하여 원복 기능을 지원하며, 변경자와 변경 사유도 기록합니다.

| 테이블명 | 컬럼명 | 데이터타입 | NULL허용 | 기본값 | PK/FK | 설명 |
|---------|--------|-----------|---------|-------|-------|------|
| tb_prompt_history | id | serial | NOT NULL | - | PK | 이력 고유 ID (자동 증가) |
| tb_prompt_history | category | varchar(50) | NOT NULL | - | FK | 설정 카테고리 (prompt) |
| tb_prompt_history | key | varchar(100) | NOT NULL | - | FK | 설정 키 (rag_system_prompt 등) |
| tb_prompt_history | old_value | text | NULL | - | - | 변경 전 값 (NULL이면 최초 생성) |
| tb_prompt_history | new_value | text | NOT NULL | - | - | 변경 후 값 |
| tb_prompt_history | changed_by | varchar(100) | NULL | - | - | 변경자 정보 (향후 사용자 인증 연동) |
| tb_prompt_history | changed_at | timestamp | NULL | CURRENT_TIMESTAMP | - | 변경 일시 |
| tb_prompt_history | change_reason | text | NULL | - | - | 변경 사유 (선택) |

**제약조건**:
- PRIMARY KEY: id
- FOREIGN KEY: (category, key) → tb_app_settings(category, key) ON DELETE CASCADE

**인덱스**:
- idx_tb_prompt_history_category_key: (category, key) 복합 인덱스
- idx_tb_prompt_history_changed_at: changed_at DESC 인덱스

---
