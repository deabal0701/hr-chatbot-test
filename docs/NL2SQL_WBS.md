# NL2SQL (Agent) 프로젝트 WBS

## 프로젝트 개요
- **프로젝트명**: MUREUM NL2SQL 시스템 구축
- **총 기간**: 4개월
- **핵심 기술**: FastAPI + LangGraph + PostgreSQL/Oracle + Vue 3 + Multi-LLM (OpenAI/Anthropic)

---

## 요구사항 요약
| 항목 | 결정 사항 |
|------|----------|
| 대상 Database | PostgreSQL + Oracle |
| 결과 시각화 | 테이블 + 기본 차트 (막대, 파이, 라인) |
| 비즈니스 용어 사전 | 불필요 (프롬프트 Few-shot으로 대체) |
| 권한 관리 | 필요 (사용자/그룹별 테이블/컬럼 접근 제한) |

### 3. 설계 (Design)

| WBS | 작업 항목 | 산출물 | 비고 |
|-----|----------|--------|------|
| **3.1** | **데이터 가공 설계** | | |
| 3.1.1 | 데이터 마스킹 설계 | 마스킹 정책서 | 급여, 개인정보 마스킹 규칙 |
| 3.1.2 | 데이터 인덱스 설계 | 인덱스 설계서 | NL2SQL 쿼리 성능 최적화 |
| 3.1.3 | 데이터 권한 설계 | 권한 설계서 | 사용자별 테이블/컬럼 접근 제어 |
| **3.2** | **AI 모델 설계** | | |
| 3.2.1 | NL2SQL 모델 프롬프트 설계 | 프롬프트 템플릿 | 스키마 포맷, Few-shot 예시 (용어 매핑 포함) |
| 3.2.2 | SQL Validation Layer 설계 | 검증 규칙서 | DDL/DML 차단, 테이블 화이트리스트 |
| 3.2.3 | 민감정보 차단 규칙 설계 | 보안 규칙서 | 결과 마스킹, 권한 기반 필터링 |
| 3.2.4 | 오류 처리 설계 | 오류 처리 정책 | 파싱 실패, 타임아웃, DB 연결 오류 |
| **3.3** | **Multi-DB 설계** | | PostgreSQL + Oracle |
| 3.3.1 | DB 어댑터 아키텍처 설계 | 아키텍처 설계서 | 통합 인터페이스 정의 |
| 3.3.2 | Oracle 스키마 로더 설계 | 스키마 로더 설계서 | Oracle 메타데이터 수집 방안 |
| 3.3.3 | SQL 방언 변환 설계 | SQL 변환 규칙서 | PostgreSQL ↔ Oracle 구문 차이 |
| **3.4** | **UI/UX 설계** | | |
| 3.4.1 | 화면 설계 (Wireframe) | 화면 설계서 | 채팅 UI, 결과 표시, 차트, 관리자 화면 |
| 3.4.2 | 차트 유형 설계 | 차트 설계서 | 막대, 파이, 라인 차트 적용 기준 |
| 3.4.3 | 사용자 경험 시나리오 | UX 시나리오 | 질문 → 결과 → 차트 → 재질문 플로우 |
