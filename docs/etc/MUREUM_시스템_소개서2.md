# MUREUM: 엔터프라이즈 AI 지식기반 어시스턴트 — 기술 소개서

> "자연어 한 줄이면, 데이터가 답한다"
> — 문서 검색부터 데이터베이스 분석, 시각화, 개인 대시보드까지 하나의 대화창에서

---

## 1. 시스템 개요

MUREUM은 기업 내 축적된 **비정형 문서**와 **정형 데이터베이스**를 자연어 대화만으로 통합 검색·분석·시각화할 수 있는 **엔터프라이즈 AI 지식기반 어시스턴트**이다.

기존 BI 도구가 전문 분석가의 SQL 작성이나 복잡한 대시보드 설정을 요구하는 반면, MUREUM은 **"2024년 부서별 매출 현황을 보여줘"** 같은 일상 언어만으로 데이터를 조회하고, 그 결과를 즉시 차트로 시각화하며, 이를 **개인 대시보드에 저장**할 수 있다.

### 핵심 기술 스택

| 구분 | 기술 |
|------|------|
| AI 엔진 | LangGraph 기반 ReAct Agent + RAG + NL2SQL |
| LLM | OpenAI GPT-4o, Anthropic Claude, Google Gemini (멀티 프로바이더) |
| 벡터 검색 | PostgreSQL pgvector + 하이브리드 검색(벡터+키워드+RRF) |
| 백엔드 | FastAPI (Python 3.13) + SSE 실시간 스트리밍 |
| 프론트엔드 | Vue 3 + ECharts 동적 시각화 |
| 보안 | JWT 인증 + 2계층 RBAC + PII 자동 마스킹 |

## 2. 3대 핵심 기능

### 2.1 자연어 데이터베이스 검색 (NL2SQL)

사용자가 입력한 자연어 질문을 **자동으로 SQL로 변환**하여 데이터베이스에서 실시간 조회한다.

**동작 과정:**
```
사용자 질문 → 의도 분석 → 스키마 매칭 → Few-shot 참조 → SQL 생성 → 검증 → 실행 → PII 필터 → 답변 생성
```

**핵심 차별점:**
- **멀티턴 대화**: "부서별 인원수 알려줘" → "그 중에서 개발팀만 연봉 순으로 보여줘"처럼 이전 맥락을 이해하는 연속 대화 지원
- **의도 재작성(Intent Rewrite)**: 대화 이력을 분석해 모호한 질문을 완전한 질문으로 재구성
- **자동 재시도**: SQL 오류 발생 시 오류 원인을 분석하여 자동으로 수정된 SQL 재생성
- **SQL 안전장치**: SELECT만 허용, 키워드 블랙리스트, 테이블 화이트리스트, 실행 타임아웃 30초 제한

### 2.2 문서 지식 검색 (RAG)

사내 정책서, 매뉴얼, FAQ 등 비정형 문서를 벡터 임베딩하여 **의미 기반 검색**을 수행한다.

**핵심 차별점:**
- **하이브리드 검색**: 벡터 유사도 + 키워드 매칭 + RRF(Reciprocal Rank Fusion) 결합으로 높은 검색 정확도
- **문서 원본 추적**: 검색 결과마다 출처 문서명, 유사도 점수, 원문 스니펫을 함께 제공
- **문서 ID 직접 참조**: 특정 문서 번호를 언급하면 해당 문서를 직접 검색

### 2.3 AI 에이전트 (ReAct 패턴)

복합적인 질문에 대해 **LLM이 스스로 도구를 선택**하여 다단계 추론을 수행한다.

```
"2024년 입사자는 몇 명이고, 재택근무 정책은 뭐야?"
  → [도구1: NL2SQL] 입사자 수 조회 → 15명
  → [도구2: RAG] 재택근무 정책 검색 → 주 2회 허용
  → 종합 답변 생성
```

**핵심 차별점:**
- 질문 유형에 따라 SQL 도구, 문서 검색 도구, 계산기 도구를 **자율적으로 조합**
- 하나의 질문에 여러 도구를 순차·반복 호출하는 **다단계 추론(Multi-step Reasoning)**
- 세션 메모리를 통한 **멀티턴 대화 유지**

## 3. 데이터 시각화 및 개인 대시보드

### 3.1 대화형 데이터 시각화 (ChartBuilder)

NL2SQL로 조회된 결과를 **대화창 내에서 즉시 차트로 변환**하는 동적 시각화 기능이다. 별도 BI 도구 없이 질문 → 데이터 조회 → 시각화까지 하나의 대화 흐름에서 완결된다.

**지원 차트 유형:**

| 차트 유형 | 용도 | 특징 |
|-----------|------|------|
| 막대 차트 (Bar) | 항목별 비교 | 다중 Y축, 스택 지원 |
| 가로 막대 (Horizontal Bar) | 긴 레이블 비교 | 자동 레이아웃 조정 |
| 꺾은선 (Line) | 추세 분석 | 부드러운 곡선, 다중 시리즈 |
| 원형/도넛 (Pie) | 구성비 분석 | Top-N 필터, "기타" 자동 그룹핑 |
| 산점도 (Scatter) | 상관관계 분석 | 2D 포인트 클라우드 |

**스마트 기능:**
- **컬럼 자동 감지**: 데이터의 첫 10행을 분석하여 숫자/문자 컬럼을 자동 분류, X축·Y축을 지능적으로 추천
- **대량 데이터 처리**: 30건 초과 시 Data Zoom 슬라이더 자동 활성화, 드래그로 구간 탐색
- **다중 Y축 지원**: 막대·꺾은선 차트에서 여러 수치 컬럼을 동시에 시각화
- **Top-N 필터**: 원형 차트에서 상위 5/10/15/20건만 표시, 나머지는 "기타(N건)"으로 자동 그룹핑
- **테마 전환**: 다크 모드 / 화이트 배경 원클릭 전환
- **6종 컬러 팔레트**: Default, Vivid, Pastel, Warm, Cool, Earth 중 선택

### 3.2 개인 대시보드 (Personal Dashboard)

자주 사용하는 질문과 차트를 **위젯으로 저장하여 나만의 대시보드를 구성**할 수 있다.

**위젯 저장 흐름:**
```
자연어 질문 → NL2SQL 결과 → 차트 생성 → "대시보드에 저장" 클릭
→ 위젯 이름·차트 설정 저장 → 개인 대시보드에 표시
```

**대시보드 특징:**
- 사용자별 개인화된 위젯 구성
- 저장된 쿼리의 **실시간 데이터 갱신** (대시보드 접근 시 최신 데이터로 자동 재조회)
- 차트 설정(차트 유형, 축 컬럼, Top-N 등)이 위젯과 함께 저장

### 3.3 관리자 대시보드 (Admin Dashboard)

시스템 운영 현황을 한눈에 파악할 수 있는 **실시간 모니터링 대시보드**이다.

**4대 KPI 카드:**

| 지표 | 내용 | 부가 정보 |
|------|------|-----------|
| 총 요청 수 | NL2SQL + RAG 전체 요청 | NL2SQL/RAG 건수 분리 표시 |
| 성공률 | 정상 응답 비율(%) | 오류 건수 뱃지 |
| 활성 사용자 | 현재 활동 중 사용자 수 | 테넌트 수 |
| 총 문서 수 | 등록된 전체 문서 | 인덱싱 완료/대기 진행률 |

**분석 차트:**
- **일별 요청 추이** (Stacked Bar): NL2SQL·RAG 일별 사용량을 적층 막대로 비교
- **검색 유형 분포** (Donut): NL2SQL vs RAG 비율을 도넛 차트로 표시
- **최근 활동 피드**: 최근 7건 요청의 유형·질문·성공여부·응답시간 실시간 표시

**운영 기능:**
- **기간 필터**: 오늘 / 최근 7일 / 최근 30일 전환
- **60초 자동 갱신**: 탭 비활성 시 자동 일시정지, 복귀 시 즉시 갱신
- **시스템 현황 패널**: LLM 모델명, 임베딩 모델, 서버 상태, 문서 인덱싱 진행률 표시

## 4. 실시간 스트리밍 UX (SSE)

AI 응답을 기다리는 동안 **처리 단계를 실시간으로 시각화**하여 사용자 경험을 극대화한다.

```
[NL2SQL 스트리밍 예시]
✓ 질문 분석 완료
✓ SQL 생성 완료
✓ SQL 실행 완료
● 답변 생성 중...  ⟵ 현재 단계 (타이핑 애니메이션)
```

**특징:**
- **단계별 진행 표시**: 완료된 단계는 ✓ 체크, 현재 단계는 애니메이션 표시
- **Forward-Only 전환**: 내부 재시도가 발생해도 UI 진행은 항상 전진 방향만 표시 (사용자 혼란 방지)
- **Agent 3단계**: 생각 중 → 도구 실행 중 → 답변 생성 중
- **NL2SQL 4단계**: 질문 분석 → SQL 생성 → SQL 실행 → 답변 생성

## 5. 엔터프라이즈 보안 체계

### 5.1 인증 및 접근 제어

| 보안 계층 | 내용 |
|-----------|------|
| **JWT 이중 토큰** | Access Token(30분) + Refresh Token(7일, DB 저장) |
| **계정 잠금** | 로그인 5회 실패 시 30분 자동 잠금 |
| **2계층 권한 모델** | 역할(GLOBAL/TENANT/USER)로 데이터 범위 제어 + 메뉴별 CRUD 권한 제어 |
| **권한 상승 방지** | 자신보다 상위 역할 할당 불가, 미보유 메뉴 권한 부여 불가 |

### 5.2 데이터 보호

| 보호 기능 | 적용 위치 |
|-----------|-----------|
| **PII 자동 마스킹** | 주민등록번호, 전화번호, 계좌번호, 이메일 등 자동 감지·마스킹 |
| **SQL 인젝션 차단** | SELECT만 허용, DDL/DML 키워드 차단, 테이블 화이트리스트 |
| **실행 제한** | 쿼리 타임아웃 30초, 결과 행수 자동 제한 |
| **감사 추적** | 모든 API 요청을 미들웨어가 자동으로 이력 DB에 기록 |

### 5.3 멀티테넌트 격리

- 테넌트별 독립 데이터베이스 연결 풀
- 역할 기반 자동 데이터 범위 필터링 (GLOBAL: 전체 / TENANT: 소속 테넌트 / USER: 본인 데이터)
- 테넌트별 AI 모델·설정 독립 구성 가능

## 6. HR을 넘어: 산업별 적용 시나리오

MUREUM은 **도메인에 종속되지 않는 범용 아키텍처**로 설계되었다. 외부 비즈니스 DB의 테이블과 문서만 교체하면 어떤 산업에도 즉시 적용 가능하다.

### 적용 방법 (3단계)
```
① 비즈니스 DB 연결 설정 (관리자 UI에서 테이블 화이트리스트 지정)
② Few-shot SQL 예제 등록 (도메인별 자연어→SQL 예시 추가)
③ 도메인 문서 업로드 (PDF/텍스트 → 자동 임베딩 → RAG 검색 대상)
```

### 산업별 적용 예시

#### 제조업 — 생산·품질 관리
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 생산실적(production), 품질검사(quality_inspection), 설비(equipment) | "이번 달 A라인 불량률 추이를 보여줘" |
| | "설비 가동률이 90% 미만인 라인은?" |
| | "품질 검사 기준서에서 경도 허용 범위 알려줘" |
| **시각화 활용** | 라인별 불량률 추이 → 꺾은선 차트 → 대시보드 위젯 저장 |

#### 금융·보험 — 리스크·실적 분석
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 거래내역(transactions), 계좌(accounts), 보험금(claims) | "이번 분기 지점별 예금 유치 실적 비교해줘" |
| | "보험금 청구 중 100만원 이상 건수는?" |
| | "여신 심사 기준 매뉴얼에서 담보인정비율 알려줘" |
| **시각화 활용** | 지점별 실적 비교 → 막대 차트 → Top-10 필터 적용 |

#### 유통·리테일 — 매출·재고 분석
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 매출(sales), 재고(inventory), 상품(products), 매장(stores) | "이번 주 카테고리별 매출 현황 보여줘" |
| | "재고 부족 예상 상품 목록 알려줘" |
| | "프로모션 운영 가이드에서 할인율 기준 찾아줘" |
| **시각화 활용** | 카테고리별 매출 구성비 → 도넛 차트 → 주간 대시보드 |

#### 의료·헬스케어 — 환자·진료 관리
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 환자(patients), 진료기록(medical_records), 처방(prescriptions) | "이번 달 진료과별 외래 환자 수 추이 보여줘" |
| | "당뇨 환자 중 최근 3개월 내 HbA1c 수치 변화는?" |
| | "감염관리 지침에서 격리 기준 알려줘" |
| **시각화 활용** | 진료과별 환자 추이 → 적층 막대 차트 → 월간 리포트 |

#### 물류·공급망 — 배송·재고 추적
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 주문(orders), 배송(shipments), 공급업체(suppliers), 창고(warehouses) | "이번 주 배송 지연 건수와 주요 원인은?" |
| | "거래처별 납품 리드타임 평균 비교해줘" |
| | "수입 통관 절차 매뉴얼 보여줘" |
| **시각화 활용** | 거래처별 리드타임 비교 → 가로 막대 차트 → 공급망 대시보드 |

#### 교육기관 — 학사·성적 관리
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 학생(students), 수강(enrollments), 성적(grades), 강좌(courses) | "이번 학기 학과별 평균 학점 분포 보여줘" |
| | "재수강 비율이 높은 과목 Top 10은?" |
| | "장학금 선발 기준 규정 알려줘" |
| **시각화 활용** | 학과별 학점 분포 → 원형 차트 → 학사 대시보드 |

#### 공공·행정 — 민원·통계 분석
| 연결 대상 | 대화 예시 |
|-----------|-----------|
| 민원(complaints), 예산(budget), 인구(demographics) | "올해 유형별 민원 접수 현황 보여줘" |
| | "예산 집행률이 50% 미만인 사업은?" |
| | "개인정보 처리 방침 최신 버전 보여줘" |

## 7. 기술적 특장점 요약

### 7.1 아키텍처 유연성

| 특장점 | 상세 |
|--------|------|
| **멀티 LLM 프로바이더** | OpenAI, Anthropic, Google Gemini를 관리자 UI에서 실시간 전환. 코드 변경 없이 모델 교체 가능 |
| **멀티 DB 어댑터** | PostgreSQL, Oracle 지원. Factory 패턴으로 MySQL, MSSQL 등 확장 용이 |
| **동적 설정 시스템** | 모든 AI 설정(모델명, 온도, 토큰 수 등)을 관리자 UI에서 실시간 변경. 서버 재시작 불필요 |
| **테넌트별 독립 구성** | 테넌트마다 다른 LLM 모델, 다른 비즈니스 DB, 다른 AI 설정 적용 가능 |

### 7.2 사용자 경험

| 특장점 | 상세 |
|--------|------|
| **자연어 원스톱** | 질문 → 데이터 조회 → 시각화 → 대시보드 저장까지 하나의 대화창에서 완결 |
| **실시간 스트리밍** | SSE 기반 단계별 진행 표시로 대기 시간 체감 최소화 |
| **멀티턴 대화** | 이전 질문 맥락을 유지하는 연속 대화. "그 중에서~", "좀 더 자세히~" 가능 |
| **개인 대시보드** | 자주 쓰는 분석 결과를 위젯으로 저장, 실시간 데이터 갱신 |
| **반응형 디자인** | 데스크톱·태블릿·모바일 자동 최적화, 다크 모드 지원 |
| **Excel 내보내기** | 조회 결과와 차트를 Excel 파일로 즉시 다운로드 |

### 7.3 보안 및 규정 준수

| 특장점 | 상세 |
|--------|------|
| **PII 자동 보호** | 주민번호·전화번호 등 개인정보를 LLM 전송 전 자동 마스킹 |
| **SQL 안전 실행** | 읽기 전용 강제, 위험 키워드 차단, 실행 시간·결과 행수 제한 |
| **완전한 감사 추적** | 모든 API 호출을 자동 기록, 요청·응답·소요시간 추적 가능 |
| **세밀한 접근 제어** | 메뉴별 CRUD 권한 + 역할별 데이터 범위 제어의 2계층 구조 |

### 7.4 운영 안정성

| 특장점 | 상세 |
|--------|------|
| **메모리 관리** | BoundedInMemorySaver로 세션 TTL(24시간)·최대 수(1,000) 자동 관리 |
| **커넥션 풀링** | 서비스 DB·비즈니스 DB 모두 커넥션 풀로 효율적 관리 |
| **오류 자동 복구** | NL2SQL SQL 오류 시 자동 재시도, LLM 프로바이더 장애 시 폴백 |
| **비동기 처리** | 전 구간 async/await 기반 비동기 처리로 높은 동시 처리 성능 |

## 9. 도입 효과

### 정량적 기대 효과
- **데이터 접근 민주화**: SQL 미숙련 직원도 자연어로 데이터 분석 가능 → 데이터 활용 인력 확대
- **분석 시간 단축**: 질문→조회→시각화까지 수 초 내 완료 (기존 BI 대시보드 설정 수십 분 → 자연어 한 줄)
- **리포트 자동화**: 반복 분석을 대시보드 위젯으로 저장, 접근 시 자동 갱신

### 정성적 기대 효과
- **데이터 기반 의사결정 문화**: 회의 중 즉석 데이터 조회·시각화 가능
- **지식 관리 효율화**: 산재된 문서·매뉴얼을 하나의 채널에서 통합 검색
- **보안 규정 준수**: 개인정보 자동 보호로 데이터 활용과 규정 준수의 균형
