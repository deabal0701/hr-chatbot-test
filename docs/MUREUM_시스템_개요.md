## 기술 스택

| 구분 | 기술 |
|------|------|
| **Backend** | Python 3.13, FastAPI, LangGraph, LangChain |
| **Frontend** | Vue 3, Element Plus, ECharts |
| **AI 엔진** | OpenAI (GPT-4o), Anthropic (Claude) — 관리 화면에서 즉시 전환 |
| **Database** | PostgreSQL (pgvector) |
| **보안** | JWT 인증, 역할 기반 접근 제어, PII 자동 마스킹 |

---

## 3가지 AI 워크플로우

| 워크플로우 | 역할 | 동작 방식 |
|-----------|------|----------|
| **NL2SQL** | 자연어 → 데이터 조회 | 질문 분석 → SQL 자동 생성 → 실행 → 자연어 답변 |
| **RAG** | 사내 문서 검색 | 질문의 의미를 이해하여 관련 문서를 찾고 핵심 요약 |
| **AI Agent** | 복합 질문 해결 | NL2SQL + RAG를 AI가 자율적으로 조합하여 답변 |

## 주요 특징

| 특징 | 설명 |
|------|------|
| **연속 대화** | 이전 질문을 기억하여 추가 질문·필터링 가능 |
| **차트 시각화** | 조회 결과를 막대·꺾은선·원형 등 5종 차트로 즉시 생성 |
| **개인 대시보드** | 자주 보는 차트를 저장 → 매일 최신 데이터로 자동 갱신 |
| **실시간 진행 표시** | AI 처리 단계를 실시간으로 표시 (SSE 스트리밍) |
| **자동 오류 복구** | SQL 오류 시 원인 분석 후 자동 수정·재실행 |
| **3단계 접근 권한** | 전체 관리자 / 부서 관리자 / 일반 사용자 |
| **설정 즉시 반영** | AI 모델·설정 변경 시 서버 재시작 없이 실시간 적용 |
