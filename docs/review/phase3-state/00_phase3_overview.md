# Phase 3. 상태 관리 - 데이터가 어디에 저장되는가?

## 이 Phase에서 배우는 것

Phase 2에서 라우터 가드가 `store.getters['auth/isAuthenticated']`를 사용하는 것을 보았습니다.
이제 이 **Store(저장소)**가 무엇이고, 앱 전체의 데이터가 **어떻게 저장되고 공유되는지** 이해합니다.

## 비유로 이해하기

Vuex Store는 **회사의 공유 게시판**과 같습니다:

```
[Store가 없다면]
각 부서(컴포넌트)가 자기만의 메모장에 정보를 기록
  → 다른 부서에 전달하려면 일일이 전화(props/emit)
  → 3단계 이상 떨어진 부서는 전달이 너무 복잡!

[Store가 있으면]
회사 중앙에 공유 게시판이 있음
  → 아무 부서에서나 게시판에 접근 가능
  → 정보 변경 시 관심있는 모든 부서가 자동으로 알림 받음
```

## Vuex Store의 5개 모듈

```
store/
├── index.js          ← 모듈들을 하나로 합치는 곳
└── modules/
    ├── auth.js       ← ⭐ 인증 (로그인, 토큰, 권한)
    ├── app.js        ← ⭐ 앱 전역 (테마, 사이드바)
    ├── chat.js       ← ⭐ 채팅 (메시지, 스트리밍, 세션)
    ├── document.js   ← 문서 관리 (CRUD, 필터, 페이지네이션)
    └── dashboard.js  ← 대시보드 (위젯, 레이아웃)
```

각 모듈은 **독립적인 담당 영역**이 있습니다:

| 모듈 | 담당 | 저장하는 데이터 |
|------|------|----------------|
| **auth** | 인증/인가 | 토큰, 사용자 정보, 메뉴 권한 |
| **app** | 앱 설정 | 다크모드, 사이드바 열림/닫힘 |
| **chat** | 채팅 기능 | 메시지 목록, 검색 모드, 세션, 스트리밍 상태 |
| **document** | 문서 관리 | 문서 목록, 필터, 페이지네이션 |
| **dashboard** | 대시보드 | 위젯 목록, 대시보드 설정, 레이아웃 |
