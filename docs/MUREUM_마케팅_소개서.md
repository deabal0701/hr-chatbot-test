# MUREUM — 물어보세요, 데이터가 답합니다

> 대화 한 줄이면 데이터 조회, 문서 검색, 차트 생성, 대시보드 저장까지.
> 프로그래밍도, 복잡한 도구도 필요 없습니다.

---

## "이런 경험, 있으시죠?"

- 데이터를 보고 싶은데 **IT팀에 요청하면 며칠이 걸린다**
- BI 도구는 **교육 없이는 쓸 수가 없다**
- 사내 매뉴얼이 **어디 있는지 찾기가 힘들다**
- 보고서용 차트를 만들려면 **엑셀과 씨름해야 한다**
- 매번 같은 데이터를 **반복해서 뽑아야 한다**

**MUREUM은 이 모든 문제를 대화 한 번으로 해결합니다.**

## 1. 텍스트로 데이터 조회 — "말로 물어보면 됩니다"

프로그래밍 언어를 몰라도 괜찮습니다. **일상 언어로 질문하면 AI가 알아서 데이터를 찾아줍니다.**

### 이렇게 질문하세요

| 이렇게 물어보면 | MUREUM이 해주는 일 |
|----------------|-------------------|
| "부서별 직원 수 알려줘" | 모든 부서의 인원수를 **표로 정리**하여 보여줌 |
| "이번 달 매출 현황 보여줘" | 매출 데이터를 조회하여 **즉시 결과 표시** |
| "연봉이 가장 높은 직원 Top 10은?" | 상위 10명을 **순위표로 정렬**하여 보여줌 |
| "2024년 입사자 몇 명이야?" | 입사자 수를 계산하여 **숫자로 답변** |

### 이전 대화를 기억합니다

한 번에 끝나는 질문만 가능한 게 아닙니다. **이전 대화를 기억**해서 연속 질문이 가능합니다.

```
나 : "부서별 인원수 알려줘"
AI : 영업부 25명, 개발팀 32명, 마케팅부 18명... (표 형태)

나 : "그 중에서 개발팀만 연봉 순으로 보여줘"
AI : (이전 대화를 기억하고) 개발팀 32명의 연봉 순위표를 표시

나 : "연봉 5,000만원 이상만 필터해줘"
AI : (계속 맥락을 유지하며) 조건에 맞는 직원 목록 표시
```

### 실수해도 걱정 없습니다

AI가 데이터를 조회하다 오류가 발생하면, **원인을 스스로 분석하고 수정하여 다시 조회**합니다. 사용자가 다시 입력할 필요가 없습니다.

### 기존 방식과 비교

| | 기존 방식 | MUREUM |
|---|-----------|--------|
| **데이터 요청** | IT팀에 요청 → 며칠 대기 | 직접 질문 → **수 초 내 결과** |
| **필요 지식** | 프로그래밍 언어(SQL) 필수 | **일상 언어**로 질문 |
| **연속 질문** | 매번 새로 요청 | **이전 맥락 기억** |
| **오류 대응** | IT팀에 재요청 | **자동 감지 후 수정** |

## 2. 사내문서 지능 검색 — "뜻만 통하면 찾아줍니다"

정확한 키워드를 몰라도 됩니다. **질문의 의미를 이해**해서 가장 적합한 답변을 찾아냅니다.

### 이렇게 질문하세요

| 이렇게 물어보면 | MUREUM이 해주는 일 |
|----------------|-------------------|
| "재택근무 할 수 있는 조건이 뭐야?" | 인사규정에서 재택근무 조항을 찾아 **핵심 내용 요약** |
| "출장비 정산은 어떻게 해?" | 경비 처리 규정에서 절차를 찾아 **단계별 안내** |
| "연차 몇 개 남았는지 어떻게 확인해?" | 연차 관련 FAQ에서 확인 방법을 찾아 **답변** |
| "신입사원 온보딩 절차 알려줘" | 온보딩 가이드에서 절차를 찾아 **순서대로 정리** |

### 기존 검색과 무엇이 다른가요?

| | 기존 사내 검색 | MUREUM |
|---|---------------|--------|
| **검색 방식** | 정확한 키워드 필요 | **비슷한 의미**로도 검색 |
| **결과 확인** | 문서를 열어서 직접 읽어야 함 | **핵심 내용을 요약**해서 답변 |
| **출처 확인** | 어떤 문서에 있는지 직접 찾아야 함 | **출처 문서명과 해당 위치**를 함께 제공 |
| **이해도** | 문서 전체를 읽어야 이해 | **질문에 맞는 부분만 발췌**하여 설명 |

## 3. 즉시 차트 시각화 — "데이터가 그림이 됩니다"

데이터 조회 결과를 **대화창 안에서 바로 차트로 변환**합니다. 엑셀을 열 필요도, 차트 설정을 배울 필요도 없습니다.

### 지원하는 차트

| 차트 종류 | 이럴 때 유용합니다 | 활용 예시 |
|-----------|-------------------|----------|
| **막대 차트** | 항목 간 크기 비교 | "부서별 매출 비교해줘" |
| **가로 막대** | 이름이 긴 항목 비교 | "거래처별 납품 실적 보여줘" |
| **꺾은선 그래프** | 시간에 따른 변화 | "월별 매출 추이 보여줘" |
| **원형/도넛** | 구성비 파악 | "유형별 비율 보여줘" |
| **산점도** | 두 수치 간 관계 | "매출과 직원 수의 관계는?" |

### 스마트 기능

- **자동 추천**: 데이터 특성에 맞는 차트 유형을 AI가 추천
- **상위 N건 필터**: 원형 차트에서 상위 5/10/15/20건만 표시, 나머지는 "기타"로 자동 묶기
- **대량 데이터 탐색**: 30건 이상 데이터도 드래그로 구간 탐색 가능
- **6종 컬러 테마**: 발표 자료에 맞는 색상 테마 선택 (밝은 색, 파스텔, 따뜻한 색 등)
- **다크/라이트 모드**: 화면 밝기에 맞춰 배경 전환
- **여러 수치 동시 비교**: 하나의 차트에 매출·인원·비용 등 복수 항목을 함께 표시

## 4. 나만의 대시보드 — "한 번 저장하면 매번 최신"

자주 확인하는 분석 결과를 **위젯으로 저장**하여, 로그인만 하면 바로 볼 수 있는 **나만의 대시보드**를 만들 수 있습니다.

### 3단계로 완성

```
① 질문하기     "부서별 매출 현황 보여줘" → 결과 확인
                         ↓
② 차트 저장    마음에 드는 차트에서 "대시보드에 저장" 클릭
                         ↓
③ 매일 확인    개인 대시보드에서 최신 데이터로 자동 갱신된 결과 확인
```

### 이런 대시보드를 만들 수 있습니다

| 업무 상황 | 대시보드 구성 예시 |
|-----------|-------------------|
| **영업팀 팀장** | 월별 매출 추이 + 영업사원별 실적 + 거래처별 매출 비중 |
| **인사담당자** | 부서별 인원 현황 + 입퇴사 추이 + 직급별 분포 |
| **생산관리자** | 라인별 생산량 + 불량률 추이 + 설비 가동률 |
| **경영진** | 전사 KPI + 부문별 매출 + 인력 현황 |

### 핵심 장점

- **여러 대시보드 생성**: 업무별, 보고 대상별로 다른 대시보드 구성
- **자동 갱신**: 대시보드를 열 때마다 최신 데이터로 자동 업데이트
- **공유 기능**: 동료에게 대시보드를 공유하여 같은 데이터 함께 확인
- **내보내기**: PNG, PDF로 저장하여 보고서에 바로 활용

## 5. 복합 질문 자동 해결 — "AI가 알아서 판단합니다"

하나의 질문에 여러 종류의 정보가 필요할 때, **사용자가 방법을 지정할 필요 없이** AI가 스스로 적절한 방법을 선택합니다.

### 이런 복합 질문이 가능합니다

```
"2024년 입사자는 몇 명이고, 재택근무 정책은 뭐야?"

AI의 처리:
  → 데이터베이스에서 입사자 수를 조회 → 15명
  → 사내 문서에서 재택근무 정책을 검색 → 주 2회 허용
  → 두 결과를 종합하여 하나의 답변으로 정리
```

```
"연차휴가 규정과 부서별 연차 사용일수를 함께 알려줘"

AI의 처리:
  → 사내 문서에서 연차 규정을 검색
  → 데이터베이스에서 부서별 연차 사용 현황을 조회
  → 규정과 실제 데이터를 함께 정리하여 답변
```

```
"자격증 보유 현황과 자격증 지원제도를 알려줘"

AI의 처리:
  → 데이터베이스에서 자격증 보유 통계를 조회
  → 사내 문서에서 자격증 취득 지원제도를 검색
  → 현황과 제도를 함께 안내
```

## 6. 인재 현황 분석 — "우리 조직을 한눈에 파악합니다"

HR 데이터베이스와 연결하면, 인재 관련 데이터를 자연어로 즉시 분석할 수 있습니다.

### 이렇게 활용하세요

| 분석 유형 | 질문 예시 |
|-----------|----------|
| **인력 현황** | "부서별 직원 수는?", "직급별 인원 분포 보여줘" |
| **입퇴사 분석** | "2024년 입사자 현황 알려줘", "최근 퇴사율 추이는?" |
| **인재 검색** | "개발팀에서 5년 이상 경력자는?", "자격증 보유자 목록" |
| **급여 분석** | "부서별 평균 연봉 비교해줘", "직급별 급여 분포는?" |
| **조직 구조** | "부서별 관리자 현황", "팀별 평균 근속연수는?" |

### 분석 → 시각화 → 대시보드까지 원스톱

```
"부서별 직원 수를 보여줘"
        ↓
  [표] 영업부 25명, 개발팀 32명, 마케팅부 18명...
        ↓
  [차트] 막대 차트로 시각화
        ↓
  [저장] "인력 현황" 위젯으로 대시보드에 저장
        ↓
  매일 출근하면 최신 인력 현황을 한눈에 확인
```

## 7. 실시간 진행 표시 — "AI가 뭘 하고 있는지 보입니다"

AI가 질문을 처리하는 동안, **지금 어떤 단계를 진행 중인지 실시간으로 표시**합니다. 답변이 올 때까지 막연히 기다릴 필요가 없습니다.

```
✓ 질문 분석 완료
✓ 데이터 조회 완료
● 답변 생성 중...  ← 지금 여기까지 진행됨
```

- 완료된 단계는 **체크(✓) 표시**
- 현재 진행 중인 단계는 **애니메이션으로 표시**
- 내부에서 재시도가 발생해도 **항상 자연스럽게 전진**

## 8. 관리자 운영 현황판 — "시스템을 한눈에 모니터링"

시스템 관리자를 위한 **실시간 운영 대시보드**를 제공합니다.

| 모니터링 항목 | 확인 가능한 정보 |
|-------------|-----------------|
| **사용량 현황** | 오늘/이번 주/이번 달 전체 요청 수 (데이터 조회 / 문서 검색 분리) |
| **성공률** | AI 정상 응답 비율 + 오류 건수 |
| **활성 사용자** | 현재 시스템 사용 중인 인원 수 |
| **문서 현황** | 등록 문서 수 + 검색 가능 상태 |
| **일별 추이** | 날짜별 사용량 변화를 차트로 추적 |
| **최근 활동** | 실시간 질문/응답 현황 피드 |
| **시스템 상태** | AI 모델, 서버 상태, 문서 처리 진행률 |

- **60초마다 자동 갱신** (다른 탭 전환 시 자동 일시정지)
- **기간 필터**: 오늘 / 최근 7일 / 최근 30일

## 보안 — "기업 환경에 맞는 철저한 보호"

### 개인정보 자동 보호

주민등록번호, 전화번호, 계좌번호 등 **개인정보가 AI에게 전달되기 전에 자동으로 마스킹**됩니다.

```
원본 데이터:  홍길동 / 010-1234-5678 / 900101-1234567
AI가 받는 데이터:  홍길동 / 010-****-5678 / 900101-*******
```

### 데이터 안전 보장

- **조회만 가능**: 데이터 수정·삭제는 시스템 차원에서 **원천 차단**
- **위험 명령 차단**: 데이터를 지우거나 변경하는 모든 시도를 자동 감지·차단
- **시간 제한**: 과도한 조회 요청은 30초 후 자동 중단

### 접근 권한 3단계

| 역할 | 볼 수 있는 데이터 | 사용 예시 |
|------|------------------|----------|
| **전체 관리자** | 전사 전체 데이터 | 경영진, IT 관리자 |
| **부서 관리자** | 소속 부서 데이터만 | 팀장, 부서장 |
| **일반 사용자** | 본인 관련 데이터만 | 일반 직원 |

### 추가 보안 기능

- **이중 인증**: 짧은 주기 + 긴 주기 이중 토큰으로 보안 강화
- **자동 잠금**: 비밀번호 5회 오류 시 30분 계정 잠금
- **감사 추적**: 누가, 언제, 무엇을 질문했는지 **자동 기록**
- **기능별 권한**: 화면마다 조회/등록/수정/삭제/내보내기 권한 개별 설정
- **조직 분리**: 멀티테넌트 아키텍처로 조직 간 **완전 격리** 운영

## 적용 가능 산업 — "어떤 업종이든 바로 적용"

업무 데이터베이스와 문서만 연결하면 **어떤 산업에서든 즉시 사용**할 수 있습니다.

### 도입 3단계

```
Step 1.  업무 데이터베이스 연결     →  관리 화면에서 클릭 몇 번으로 설정
Step 2.  질문-답변 예시 등록        →  우리 업종에 맞는 질문 예시를 추가
Step 3.  사내 문서 업로드           →  PDF·텍스트 파일을 올리면 자동으로 검색 가능
```

### 산업별 활용 시나리오

| 산업 | 대표 질문 예시 | 대시보드 활용 |
|------|---------------|-------------|
| **제조** | "A라인 불량률 추이 보여줘" | 라인별 불량률 → 일일 품질 모니터링 |
| **금융** | "지점별 예금 유치 실적 비교해줘" | 지점 Top-10 → 주간 실적 현황판 |
| **유통** | "카테고리별 매출 현황" | 매출 구성비 → 주간 보고용 대시보드 |
| **의료** | "진료과별 외래 환자 수 추이" | 환자 추이 → 월간 경영 회의 자료 |
| **물류** | "거래처별 리드타임 비교" | 납기 현황 → 공급망 관리 대시보드 |
| **교육** | "학과별 학점 분포 보여줘" | 학점 분포 → 학사 관리 대시보드 |
| **공공** | "유형별 민원 현황 보여줘" | 민원 추이 → 실시간 모니터링 |
| **HR** | "부서별 인원수와 평균 근속연수" | 인력 현황 → 인재 관리 대시보드 |

| 업무 | Before | After |
|------|--------|-------|

| **회의 중 데이터** | "확인 후 보고하겠습니다" | **"잠깐, 바로 확인해볼게요"** |

### 기대 효과

- **데이터 활용 인력 확대**: 프로그래밍을 몰라도 모든 직원이 데이터 분석 가능
- **분석 시간 단축**: 기존 수십 분 → 수 초로 **90% 이상 단축**
- **보고서 자동화**: 반복 분석을 대시보드로 저장하여 매번 갱신 불필요
- **데이터 기반 의사결정**: 회의 중 즉석 데이터 조회로 **실시간 의사결정** 가능
- **지식 관리 통합**: 흩어진 문서·매뉴얼을 **하나의 채널에서 통합 검색**
