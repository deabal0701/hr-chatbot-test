# Phase 2. 라우팅 - 화면이 어떻게 전환되는가?

## 이 Phase에서 배우는 것

Phase 1에서 `<router-view />`가 URL에 따라 화면을 바꾼다는 것을 배웠습니다.
이제 **그 규칙이 어떻게 정의되어 있는지**, 그리고 **누가 어떤 화면에 접근할 수 있는지**를 이해합니다.

## 비유로 이해하기

라우터는 **호텔의 안내 데스크**와 같습니다:

```
손님(사용자)이 "501호(URL)에 가고 싶어요" 라고 말하면

안내 데스크(라우터)가:
  1. "501호는 이 건물에 있나요?" → 라우트 정의에서 확인
  2. "투숙객(로그인) 맞으시죠?" → 인증 확인
  3. "501호는 VIP 층인데, VIP 카드 있으세요?" → 권한 확인
  4. "네, 이쪽으로 오세요" → 해당 화면 표시
     또는
  4. "죄송합니다, 로비(로그인)로 돌아가주세요" → 리다이렉트
```

## 핵심 파일

이 Phase에서 다루는 파일은 **단 하나**입니다:

| 파일 | 역할 | 줄 수 |
|------|------|-------|
| `frontend/src/router/index.js` | 모든 라우팅 규칙 + 권한 가드 | ~197줄 |

하지만 이 파일이 하는 일이 많아서, **3개의 리뷰 문서**로 나누어 설명합니다.

## 이 파일의 3가지 역할

```
router/index.js
│
├─ ① 라우트 정의 (routes 배열)
│    "어떤 URL이 어떤 화면과 연결되는가?"
│
├─ ② 네비게이션 가드 (beforeEach)
│    "이 사용자가 이 화면에 접근해도 되는가?"
│
└─ ③ 페이지 타이틀 (afterEach)
│    "브라우저 탭에 뭐라고 표시할까?"
```
