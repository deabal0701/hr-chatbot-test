## 판정 기준

| 판정 | 의미 |
|------|------|
| `PASS` | SQL 생성 + 실행 성공 + 1행 이상 + 답변 생성 + 일관성 O |
| `PASS-INCONSISTENT` | PASS이나 2회 실행 SQL 불일치 |
| `WARN-EMPTY` | SQL 실행 성공이나 결과 0행 |
| `WARN-NOANSWER` | 결과는 있으나 답변 없음 |
| `FAIL-SQL` | SQL 미생성 |
| `FAIL-EXEC` | SQL 생성됐으나 실행 실패 |
| `FAIL-API` | HTTP/서버 오류 |
