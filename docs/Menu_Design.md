# 메뉴 관리 화면 설계서

## 1. 화면 개요

메뉴 관리는 **좌측 트리 패널 + 우측 상세설정 패널**의 2-패널 레이아웃으로 구성한다.
왼쪽에서 메뉴를 선택하면 오른쪽에 해당 메뉴의 상세 정보가 표시되어 바로 수정할 수 있다.

## 3. 왼쪽 패널: 메뉴 트리

### 3.1 툴바

```
┌──────────────────────────────────┐
│ [+ 메뉴추가]  [펼치기] [접기]      │
└──────────────────────────────────┘
```

| 버튼 | 동작 |
|------|------|
| + 메뉴추가 | 루트 레벨에 새 메뉴 추가 (우측 패널이 빈 폼으로 전환) |
| 펼치기 | 트리 전체 펼침 |
| 접기 | 트리 전체 접기 |

### 3.2 트리 노드 표시

```
📁 시스템관리              [+ 하위추가]     ← hover 시 표시
├─ 👤 사용자관리           [+ 하위추가]
│  ├─ 📄 사용자목록
│  └─ 📄 사용자등록
├─ 🔐 권한관리
└─ 🏢 테넌트관리

📁 게시판                 [+ 하위추가]
├─ 📄 공지사항
└─ 📄 Q&A

📄 대시보드
📄 문서관리
📄 검색이력
```

**노드 표시 규칙:**
- `📁` DIRECTORY: 폴더 아이콘 (하위 메뉴 그룹용)
- `📄` PAGE: DB에 저장된 아이콘으로 표시
- `🔗` API: API 아이콘
- 비활성 메뉴: 회색 텍스트 + ~~취소선~~ 표시
- 선택된 메뉴: 배경색 하이라이트

### 3.3 드래그앤드롭 (순서/구조 변경)

Element Plus `el-tree`의 `draggable` 속성으로 구현한다.

```
el-tree 속성:
  draggable                          ← 드래그 활성화
  :allow-drop="handleAllowDrop"      ← 드롭 가능 여부 제어
  :allow-drag="handleAllowDrag"      ← 드래그 가능 여부 제어
  @node-drop="handleNodeDrop"        ← 드롭 완료 시 DB 저장
```

**드롭 타입 3가지:**

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  드래그: 📄 문서관리                                       │
│                                                         │
│  ──── before ────  📁 시스템관리    ← 앞으로 이동 (형제)   │
│                    ├─ 👤 사용자관리                       │
│                    └─ 🔐 권한관리                        │
│  ──── after ─────                  ← 뒤로 이동 (형제)    │
│                                                         │
│  ═══ inner ═══    📁 시스템관리     ← 하위로 이동 (자식)   │
│                    ├─ 👤 사용자관리                       │
│                    ├─ 🔐 권한관리                        │
│                    └─ 📄 문서관리   ← 여기에 추가됨!       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

| 드롭 타입 | 동작 | DB 변경 |
|-----------|------|---------|
| `before` | 대상 노드 앞으로 이동 | parent_menu_id = 대상의 부모, sort_order 재계산 |
| `after` | 대상 노드 뒤로 이동 | parent_menu_id = 대상의 부모, sort_order 재계산 |
| `inner` | 대상 노드의 하위로 이동 | parent_menu_id = 대상 menu_id, depth +1 |

**드래그 제한 규칙 (`allowDrop`, `allowDrag`):**

```javascript
// 드래그 가능 여부
const handleAllowDrag = (draggingNode) => {
  // 모든 노드 드래그 가능
  return true
}

// 드롭 가능 여부
const handleAllowDrop = (draggingNode, dropNode, type) => {
  // 규칙 1: 최대 depth 5 제한
  if (type === 'inner') {
    const targetDepth = dropNode.data.depth + 1
    const draggingMaxDepth = getMaxChildDepth(draggingNode.data)
    if (targetDepth + draggingMaxDepth > 5) return false
  }
  // 규칙 2: API 타입은 하위 메뉴를 가질 수 없음
  if (type === 'inner' && dropNode.data.menu_type === 'API') {
    return false
  }
  return true
}
```

**드롭 완료 처리 (`handleNodeDrop`):**

```
@node-drop 이벤트 발생
  → 1. 이동된 노드의 새로운 parent_menu_id 결정
  → 2. 같은 레벨 형제들의 sort_order 재계산
  → 3. PUT /api/admin/v1/menus/{menu_id} 호출 (parent + sort_order 저장)
  → 4. 필요 시 형제들의 sort_order도 일괄 업데이트
  → 5. 트리 재로딩
```

### 3.4 우클릭 컨텍스트 메뉴

`el-tree`의 `@node-contextmenu` 이벤트로 구현한다.

```
┌─────────────────────┐
│  📁 시스템관리        │
│  ├─ 👤 사용자관리     │ ← 우클릭!
│  ├─ 🔐 권한관리      │     ┌──────────────────┐
│  └─ 🏢 테넌트관리    │     │ + 하위 메뉴 추가   │
│                     │     │ ──────────────── │
│                     │     │ ⬆ 위로 이동       │
│                     │     │ ⬇ 아래로 이동      │
│                     │     │ ──────────────── │
│                     │     │ 🗑 삭제           │
│                     │     └──────────────────┘
└─────────────────────┘
```

| 메뉴 항목 | 동작 | 조건 |
|-----------|------|------|
| + 하위 메뉴 추가 | 해당 노드 아래 새 메뉴 생성 모드 | DIRECTORY/PAGE 타입만 |
| ⬆ 위로 이동 | sort_order를 이전 형제와 교환 | 첫 번째 아이템이 아닐 때 |
| ⬇ 아래로 이동 | sort_order를 다음 형제와 교환 | 마지막 아이템이 아닐 때 |
| 🗑 삭제 | 확인 후 메뉴 삭제 | 하위 메뉴 없을 때만 |

## 6. 데이터 흐름

### 6.1 초기 로딩
```
MenusView mounted
  → GET /api/admin/v1/menus (트리 조회)
  → 왼쪽 트리에 전체 메뉴 표시
  → 우측 패널: "메뉴를 선택하세요" 상태
```

### 6.2 메뉴 선택
```
왼쪽 트리에서 노드 클릭
  → selectedMenu = 클릭된 메뉴 데이터
  → 우측 패널에 상세 정보 표시 (수정 모드)
```

### 6.3 메뉴 추가 (루트)
```
[+ 메뉴추가] 클릭
  → selectedMenu = null
  → 우측 패널: 빈 폼 (생성 모드)
  → parent_menu_id = null
```

### 6.4 하위 메뉴 추가
```
트리 노드의 [+ 하위추가] 또는 우클릭 "하위 메뉴 추가" 클릭
  → selectedMenu = null
  → 우측 패널: 빈 폼 (생성 모드)
  → parent_menu_id = 클릭된 노드의 menu_id (자동 세팅)
```

### 6.5 저장 (수정)
```
[저장] 클릭
  → 유효성 검사
  → PUT /api/admin/v1/menus/{menu_id} (수정)
  → 트리 재로딩 + 해당 메뉴 재선택
  → 성공 메시지
```

### 6.6 생성
```
[생성] 클릭
  → 유효성 검사
  → POST /api/admin/v1/menus (생성)
  → 트리 재로딩
  → 생성된 메뉴 자동 선택
  → 성공 메시지
```

### 6.7 삭제
```
우측 패널 [삭제] 또는 우클릭 메뉴 [삭제] 클릭
  → 확인 다이얼로그 ("정말 삭제하시겠습니까?")
  → 하위 메뉴 존재 시 에러 ("하위 메뉴를 먼저 삭제하세요")
  → DELETE /api/admin/v1/menus/{menu_id}
  → 트리 재로딩
  → 우측 패널: "메뉴를 선택하세요" 상태
  → 성공 메시지
```

### 6.8 드래그앤드롭 이동
```
트리에서 노드를 드래그하여 다른 위치에 드롭
  → @node-drop(draggingNode, dropNode, dropType) 이벤트 발생
  → dropType에 따라 처리:
     'before' → 대상 앞으로 (형제)
     'after'  → 대상 뒤로 (형제)
     'inner'  → 대상의 하위로 (자식)
  → PUT /api/admin/v1/menus/{menu_id} (parent_menu_id + sort_order 저장)
  → 형제 노드들의 sort_order 일괄 업데이트 (PUT /api/admin/v1/menus/reorder)
  → 트리 재로딩
  → 이동된 메뉴 재선택
```

### 6.9 위로/아래로 이동 (우클릭 메뉴)
```
우클릭 → [위로 이동] 또는 [아래로 이동]
  → 같은 부모의 형제 노드와 sort_order 교환
  → PUT /api/admin/v1/menus/reorder (일괄)
  → 트리 재로딩
```

## 7. 백엔드 API (추가 필요)

### 기존 API
| Method | URL | 설명 |
|--------|-----|------|
| GET | /api/admin/v1/menus | 메뉴 트리 조회 |
| POST | /api/admin/v1/menus | 메뉴 생성 |
| GET | /api/admin/v1/menus/{id} | 메뉴 상세 |
| PUT | /api/admin/v1/menus/{id} | 메뉴 수정 (parent_menu_id, sort_order 포함) |
| DELETE | /api/admin/v1/menus/{id} | 메뉴 삭제 |

### 추가 API
| Method | URL | 설명 |
|--------|-----|------|
| PUT | /api/admin/v1/menus/reorder | 형제 노드 sort_order 일괄 변경 |

**reorder API 요청 형식:**
```json
{
  "items": [
    { "menu_id": 4, "sort_order": 1 },
    { "menu_id": 5, "sort_order": 2 },
    { "menu_id": 6, "sort_order": 3 }
  ]
}
```

## 8. 트리 구조 예시 (DB 데이터)

### 기본 상태 (마이그레이션 직후 - 모두 flat)
```
📄 대시보드        (PAGE, depth=0, sort=1)
📄 자연어 검색     (PAGE, depth=0, sort=2)
📄 문서 관리       (PAGE, depth=0, sort=3)
📄 사용자 관리     (PAGE, depth=0, sort=4)
```

```
        ├── 활성화 (el-switch)
        ├── 설명 (el-input textarea)
```

## 11. Element Plus 컴포넌트 매핑

| 타입 뱃지 | `el-tag` | DIRECTORY=warning, PAGE=success, API=info |

## 12. 메뉴 조작 방법 총정리

| 작업 | 방법 1 | 방법 2 |
|------|--------|--------|
| **메뉴 추가 (루트)** | 툴바 [+ 메뉴추가] | - |
| **하위 메뉴 추가** | 노드 hover [+ 하위추가] | 우클릭 → 하위 메뉴 추가 |
| **메뉴 수정** | 트리 클릭 → 우측 폼 수정 → [저장] | - |
| **메뉴 삭제** | 우측 패널 [삭제] | 우클릭 → 삭제 |
| **순서 변경** | 드래그앤드롭 (before/after) | 우클릭 → 위로/아래로 이동 |
| **부모 변경** | 드래그앤드롭 (inner) | 우측 패널 "상위 메뉴" 셀렉트 변경 |
| **루트로 승격** | 드래그앤드롭 (루트 레벨로 드롭) | 우측 패널 "상위 메뉴" 비우기 (clearable) |

## 13. 기존 대비 변경점 요약

| 항목 | 기존 (테이블+다이얼로그) | 신규 (트리+상세패널+드래그) |
|------|----------------------|--------------------------|
| 레이아웃 | 단일 테이블 + 팝업 다이얼로그 | 좌측 트리 + 우측 인라인 폼 |
| 메뉴 선택 | 테이블 행 클릭 → 다이얼로그 | 트리 노드 클릭 → 우측 패널 |
| 추가 | 상단 버튼 → 다이얼로그 | 상단 버튼 / hover 하위추가 / 우클릭 |
| 수정 | 행 수정 버튼 → 다이얼로그 | 트리 선택 → 우측에서 직접 수정 |
| 삭제 | 행 삭제 버튼 | 우측 패널 / 우클릭 메뉴 |
| 순서 변경 | sort_order 숫자 직접 입력 | **드래그앤드롭** / 우클릭 위로·아래로 |
| 부모 변경 | 불가 | **드래그앤드롭** / 상위 메뉴 셀렉트 |
| 아이콘 | 텍스트만 | **미리보기 포함** |
| 컨텍스트 메뉴 | 없음 | **우클릭 메뉴** (추가/이동/삭제) |
