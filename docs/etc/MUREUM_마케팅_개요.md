# MUREUM — 물어보세요, HR 데이터가 답합니다

> 대화 한 줄이면 인사 데이터 조회, 사내 문서 검색, 차트 생성, 대시보드 저장까지.
> SQL도, BI 도구도, 전문 교육도 필요 없습니다.

---

## 현재의 문제

| 지금은... | MUREUM이면... |
|-----------|--------------|
| 인원 현황 하나 보려면 **IT팀에 요청 → 며칠 대기** | 직접 질문 → **수 초 내 결과** |
| BI 도구는 **교육 없이 쓸 수 없다** | **대화만 하면 된다** |
| 사내 규정이 **어디 있는지 찾기 힘들다** | 질문하면 **핵심만 요약** |
| 보고서용 차트 만들려면 **엑셀과 씨름** | 대화 한 줄로 **즉시 차트** |
| 같은 데이터를 **매번 반복해서 추출** | 대시보드 저장 → **자동 갱신** |

## 핵심 기능

| 기능 | 설명 | 활용 예시 |
|------|------|----------|
| **자연어 데이터 조회** | 일상 언어로 질문하면 AI가 HR DB에서 데이터를 조회 | "부서별 직원 수 알려줘", "2024년 입사자 몇 명?" |
| **사내 문서 검색** | 인사규정·매뉴얼·FAQ를 의미 기반으로 검색, 핵심 요약 | "재택근무 조건이 뭐야?", "출장비 정산 절차" |
| **즉시 차트 생성** | 조회 결과를 막대·꺾은선·원형 등 5종 차트로 즉시 시각화 | "직급별 인원 분포 차트로 보여줘" |
| **개인 대시보드** | 자주 보는 차트를 저장 → 매일 최신 데이터로 자동 갱신 | 인력 현황 + 입퇴사 추이 + 직급 분포 |
| **복합 질문 해결** | 데이터 조회 + 문서 검색을 AI가 자동 조합하여 답변 | "입사자 수와 재택근무 정책 함께 알려줘" |
| **연속 대화** | 이전 맥락을 기억하여 추가 질문·필터링 가능 | "그 중에서 개발팀만 연봉 순으로" |

## HR 활용 시나리오

```
👤 "부서별 직원 수 보여줘"
   → [표] 영업부 25명, 개발팀 32명, 마케팅부 18명...
   → [차트] 막대 차트로 시각화
   → [저장] 대시보드에 위젯으로 저장
   → 매일 출근하면 최신 인력 현황을 한눈에 확인

👤 "연차휴가 규정과 부서별 연차 사용일수를 함께 알려줘"
   → 사내 문서에서 연차 규정 검색 + DB에서 사용 현황 조회
   → 규정과 실제 데이터를 하나의 답변으로 정리
```
