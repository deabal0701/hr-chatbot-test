# MUREUM: AI 지식기반 어시스턴트

> **"말로 물어보면, 데이터가 답합니다"**
> — 문서 검색, 데이터 분석, 차트 시각화, 나만의 대시보드까지 대화 한 번으로

---

## 1. MUREUM이란?

회사에 쌓여 있는 데이터와 문서, 활용하고 싶지만 이런 어려움이 있지 않으셨나요?

- "데이터를 보려면 IT팀에 요청해야 해서 며칠씩 걸린다"
- "BI 도구는 너무 복잡해서 교육 없이는 사용이 어렵다"
- "사내 매뉴얼이 어디 있는지 찾기가 힘들다"

**MUREUM**은 이런 문제를 해결합니다.

그냥 대화창에 **"이번 달 부서별 매출 현황 보여줘"** 라고 입력하면, AI가 자동으로 데이터를 찾아서 표와 차트로 보여주고, 마음에 드는 결과는 **나만의 대시보드에 저장**까지 할 수 있습니다.

**프로그래밍 지식도, 복잡한 도구 사용법도 필요 없습니다. 그냥 말로 물어보세요.**

---

## 2. 핵심 기능 3가지

### 2.1 데이터베이스에 말로 질문하기

기존에는 데이터를 조회하려면 전문가가 프로그래밍 언어로 질의문을 작성해야 했습니다. MUREUM은 **일상 언어를 자동으로 데이터 질의문으로 변환**하여 실시간으로 결과를 보여줍니다.

**이렇게 사용합니다:**

> **나**: "부서별 인원수 알려줘"
> **MUREUM**: 영업부 25명, 개발팀 32명, 마케팅부 18명... (표 형태로 표시)
>
> **나**: "그 중에서 개발팀만 연봉 순으로 보여줘"
> **MUREUM**: (이전 대화를 기억하고) 개발팀 32명의 연봉 순위표를 표시

**무엇이 다른가요?**

| 기존 방식 | MUREUM |
|-----------|--------|
| IT팀에 데이터 요청 → 며칠 대기 | 직접 질문 → **즉시 결과** |
| 전문 질의문 작성 필요 | **일상 언어**로 질문 |
| 매번 새로 요청 | **이전 대화를 기억**하는 연속 질문 |
| 오류 시 재요청 | **자동으로 오류를 감지하고 수정** |

### 2.2 사내 문서 지능형 검색

정책서, 매뉴얼, FAQ 등 사내 문서를 **의미를 이해하는 방식으로 검색**합니다. 단순 키워드 매칭이 아니라, 질문의 의도를 파악하여 가장 적합한 답변을 찾아냅니다.

**이렇게 사용합니다:**

> **나**: "재택근무 시 출장비 처리는 어떻게 해?"
> **MUREUM**: 「인사규정 제23조」에 따르면, 재택근무 중 출장 시...
> (출처: 인사규정_2024.pdf, 23페이지)

**무엇이 다른가요?**

| 기존 방식 | MUREUM |
|-----------|--------|
| 폴더를 하나하나 뒤져 찾기 | **질문 의도를 파악**하여 자동 검색 |
| 정확한 키워드를 알아야 검색 가능 | **비슷한 의미**로도 찾아줌 |
| 문서를 열어서 직접 읽어야 함 | **핵심 내용을 요약**하여 답변 |
| 어떤 문서에 있는지 모름 | **출처 문서와 해당 위치** 함께 제공 |

### 2.3 복합 질문 자동 해결 (AI 에이전트)

**하나의 질문에 여러 종류의 정보가 필요할 때**, AI가 스스로 판단하여 데이터베이스 조회와 문서 검색을 조합합니다.

**이렇게 사용합니다:**

> **나**: "2024년 입사자는 몇 명이고, 재택근무 정책은 뭐야?"
> **MUREUM**:
> - 데이터 조회 결과: 2024년 신규 입사자는 **15명**입니다.
> - 문서 검색 결과: 재택근무는 **주 2회까지 허용**되며... (출처: 인사규정)

사용자가 "이건 데이터베이스에서 찾고, 저건 문서에서 찾아라"라고 지시할 필요 없이, **AI가 알아서 적절한 방법을 선택**합니다.

## 3. 질문 → 차트 → 나만의 대시보드

### 3.1 질문하면 바로 차트로

데이터를 조회하면 **대화창 안에서 바로 차트가 생성**됩니다. 별도 프로그램을 열거나 복잡한 설정을 할 필요가 없습니다.

> **나**: "부서별 매출 현황 보여줘"
> **MUREUM**: (표 + 막대 차트를 함께 표시)

**다양한 차트를 지원합니다:**

| 차트 종류 | 이럴 때 유용합니다 |
|-----------|-------------------|
| 막대 차트 | "부서별 매출 비교해줘" — 항목 간 크기 비교 |
| 가로 막대 | "거래처별 납품 실적 보여줘" — 이름이 긴 항목 비교 |
| 꺾은선 그래프 | "월별 매출 추이 보여줘" — 시간에 따른 변화 확인 |
| 원형/도넛 | "유형별 비율 보여줘" — 구성비 한눈에 파악 |
| 산점도 | "매출과 직원 수의 관계는?" — 두 수치 간 관계 분석 |

**편리한 기능들:**
- 데이터에 맞는 차트 유형을 **자동으로 추천**
- 데이터가 많을 때 구간을 **드래그하여 탐색** 가능
- 상위 5건/10건만 보기, 나머지는 "기타"로 자동 묶기
- 6가지 컬러 테마 선택 (밝은 색, 파스텔, 따뜻한 색 등)
- **다크 모드** 지원

### 3.2 나만의 대시보드 만들기

자주 확인하는 분석 결과를 **위젯으로 저장**하여, 로그인만 하면 바로 볼 수 있는 나만의 대시보드를 만들 수 있습니다.

**사용 흐름:**

```
① "부서별 매출 현황 보여줘" → 결과 확인
② 마음에 드는 차트에서 "대시보드에 저장" 클릭
③ 위젯 이름 입력 → 저장 완료
④ 개인 대시보드에서 언제든 확인 (최신 데이터로 자동 갱신)
```

**핵심 장점:**
- 한 번 저장하면 매번 같은 질문을 반복할 필요 없음
- 대시보드를 열 때마다 **최신 데이터로 자동 갱신**
- 차트 유형, 색상 등 설정이 그대로 유지

### 3.3 관리자 운영 현황판

시스템 관리자를 위한 **운영 현황 대시보드**도 제공합니다.

| 한눈에 볼 수 있는 정보 | 설명 |
|----------------------|------|
| 총 질문 수 | 오늘/이번 주/이번 달 전체 사용량 |
| 성공률 | AI가 정상 응답한 비율 |
| 활성 사용자 수 | 현재 시스템을 사용 중인 인원 |
| 등록 문서 수 | 검색 가능한 전체 문서 현황 |

- 일별 사용량 추이 차트로 **활용도 변화 추적**
- 최근 질문 목록으로 **실시간 사용 현황 모니터링**
- 기간별 필터 (오늘 / 최근 7일 / 최근 30일)
- **60초마다 자동 갱신** (다른 탭 전환 시 자동 일시정지)

## 4. AI가 답변하는 과정이 눈에 보입니다

AI가 질문을 처리하는 동안 **지금 어떤 단계를 진행 중인지 실시간으로 표시**합니다. "답변이 올 때까지 화면만 보고 기다리는" 답답함이 없습니다.

```
✓ 질문 분석 완료
✓ 데이터 조회 완료
● 답변 생성 중...  ← 지금 여기까지 진행됨
```

- 완료된 단계는 **체크(✓) 표시**
- 현재 진행 중인 단계는 **애니메이션으로 표시**
- 내부에서 재시도가 발생해도 화면에서는 **항상 자연스럽게 전진**

## 5. 기업 환경에 맞는 철저한 보안

### 5.1 접근 권한을 세밀하게 제어합니다

| 보안 기능 | 설명 |
|-----------|------|
| **이중 인증 토큰** | 짧은 주기와 긴 주기의 인증을 이중으로 적용하여 보안 강화 |
| **자동 계정 잠금** | 비밀번호를 5회 틀리면 30분간 자동 잠금 |
| **역할별 데이터 범위** | 전체 관리자 / 부서 관리자 / 일반 사용자별로 볼 수 있는 데이터 범위가 다름 |
| **기능별 권한 제어** | 화면(메뉴)마다 조회/등록/수정/삭제/내보내기 권한을 개별 설정 |
| **권한 상승 차단** | 자신보다 높은 권한을 다른 사용자에게 부여할 수 없음 |

### 5.2 개인정보를 자동으로 보호합니다

| 보호 대상 | 동작 방식 |
|-----------|-----------|
| 주민등록번호, 전화번호, 계좌번호 등 | AI에게 전달되기 전에 **자동으로 가려짐** (예: 010-****-5678) |
| 데이터베이스 보호 | **조회만 가능**, 데이터를 수정·삭제하는 것은 원천 차단 |
| 사용 이력 | 누가, 언제, 무엇을 질문했는지 **자동으로 기록** (감사 추적) |

### 5.3 조직별 완전 분리 운영

하나의 시스템에서 **여러 조직(부서, 계열사, 고객사)을 완전히 분리**하여 운영할 수 있습니다.

- 각 조직은 **자기 조직의 데이터만** 조회 가능
- 조직마다 **별도의 업무 데이터베이스** 연결 가능
- 조직별 **AI 모델과 설정을 독립적으로 구성** 가능

## 6. 어떤 업종에든 바로 적용 가능합니다

MUREUM은 **특정 업종에 종속되지 않는 범용 시스템**입니다. 업무 데이터베이스를 연결하고 관련 문서를 등록하면, 어떤 산업에서든 바로 사용할 수 있습니다.

### 도입 3단계

```
① 업무 데이터베이스 연결  →  관리 화면에서 클릭 몇 번으로 설정
② 질문-답변 예시 등록     →  우리 업종에 맞는 질문 예시를 추가
③ 사내 문서 업로드        →  PDF·텍스트 파일을 올리면 자동으로 검색 가능
```

### 산업별 활용 예시

#### 제조업 — 생산/품질 관리
> "이번 달 A라인 불량률 추이를 보여줘"
> "설비 가동률이 90% 미만인 라인은?"
> "품질 검사 기준서에서 경도 허용 범위 알려줘"
>
> 활용 예: 라인별 불량률 추이 차트 → 대시보드에 저장하여 매일 모니터링

#### 금융/보험 — 실적/리스크 분석
> "이번 분기 지점별 예금 유치 실적 비교해줘"
> "보험금 청구 중 100만원 이상 건수는?"
> "여신 심사 매뉴얼에서 담보인정비율 알려줘"
>
> 활용 예: 지점별 실적 비교 차트 → Top-10 필터 적용하여 핵심 지점만 추적

#### 유통/리테일 — 매출/재고 분석
> "이번 주 카테고리별 매출 현황 보여줘"
> "재고 부족 예상 상품 목록 알려줘"
> "프로모션 운영 가이드에서 할인율 기준 찾아줘"
>
> 활용 예: 카테고리별 매출 구성비 도넛 차트 → 주간 보고용 대시보드

#### 의료/헬스케어 — 환자/진료 관리
> "이번 달 진료과별 외래 환자 수 추이 보여줘"
> "당뇨 환자 중 최근 3개월 내 수치 변화는?"
> "감염관리 지침에서 격리 기준 알려줘"
>
> 활용 예: 진료과별 환자 추이 차트 → 월간 경영 회의 자료로 활용

#### 물류/공급망 — 배송/재고 추적
> "이번 주 배송 지연 건수와 주요 원인은?"
> "거래처별 납품 리드타임 평균 비교해줘"
> "수입 통관 절차 매뉴얼 보여줘"
>
> 활용 예: 거래처별 리드타임 비교 차트 → 공급망 관리 대시보드

#### 교육기관 — 학사/성적 관리
> "이번 학기 학과별 평균 학점 분포 보여줘"
> "재수강 비율이 높은 과목 Top 10은?"
> "장학금 선발 기준 규정 알려줘"
>
> 활용 예: 학과별 학점 분포 차트 → 학사 관리 대시보드

#### 공공/행정 — 민원/통계 분석
> "올해 유형별 민원 접수 현황 보여줘"
> "예산 집행률이 50% 미만인 사업은?"
> "개인정보 처리 방침 최신 버전 보여줘"
>
> 활용 예: 월별 민원 추이 차트 → 실시간 모니터링 대시보드

## 7. MUREUM만의 강점

### 7.1 누구나 쉽게 쓸 수 있습니다

| 강점 | 설명 |
|------|------|
| **대화 한 번에 끝** | 질문 → 데이터 조회 → 차트 → 대시보드 저장까지 하나의 채팅창에서 완결 |
| **이전 대화를 기억** | "그 중에서~", "좀 더 자세히~" 같은 연속 질문이 가능 |
| **처리 과정이 보임** | AI가 답변을 만드는 과정을 실시간으로 보여주어 안심하고 기다릴 수 있음 |
| **나만의 대시보드** | 자주 보는 분석 결과를 저장해두면 매번 같은 질문을 반복하지 않아도 됨 |
| **어디서든 사용** | PC, 태블릿, 모바일 모두 지원, 다크 모드 제공 |
| **Excel 내보내기** | 조회 결과를 Excel 파일로 바로 다운로드 |

### 7.2 시스템을 유연하게 운영할 수 있습니다

| 강점 | 설명 |
|------|------|
| **AI 모델 자유 교체** | OpenAI, Anthropic, Google 등 최신 AI 모델을 관리 화면에서 즉시 전환 |
| **다양한 DB 연결** | PostgreSQL, Oracle 등 기존 업무 시스템과 바로 연결 |
| **설정 즉시 반영** | AI 관련 설정을 관리 화면에서 변경하면 서버 재시작 없이 즉시 적용 |
| **조직별 맞춤 설정** | 조직마다 다른 AI 모델, 다른 데이터베이스, 다른 설정을 독립적으로 운영 |

### 7.3 보안 걱정 없이 사용할 수 있습니다

| 강점 | 설명 |
|------|------|
| **개인정보 자동 보호** | 주민번호, 전화번호 등이 AI에게 전달되기 전에 자동으로 가려짐 |
| **데이터 안전 보장** | 데이터 조회만 가능하고, 수정/삭제는 원천 차단 |
| **모든 활동 자동 기록** | 누가 언제 무엇을 질문했는지 자동 기록되어 감사 대응 가능 |
| **세밀한 권한 관리** | 화면별, 기능별, 데이터 범위별 접근 권한을 정밀하게 설정 |

### 7.4 안정적으로 운영됩니다

| 강점 | 설명 |
|------|------|
| **자동 메모리 관리** | 장시간 운영해도 시스템 리소스를 자동으로 관리하여 성능 유지 |
| **오류 자동 복구** | 데이터 조회 오류 시 원인을 분석하여 자동으로 재시도 |
| **높은 동시 처리** | 여러 사용자가 동시에 사용해도 빠른 응답 속도 유지 |

## 9. 도입하면 이렇게 달라집니다

### 업무 효율 개선

| Before | After |
|--------|-------|
| 데이터 조회를 IT팀에 요청 → **수일 대기** | 직접 질문 → **수 초 내 결과** |
| BI 도구 설정에 **수십 분 소요** | 대화 한 줄로 **즉시 차트 생성** |
| 반복 분석을 **매번 처음부터** | 대시보드 저장 → **접근만 하면 최신 데이터** |
| SQL 전문가만 데이터 활용 | **모든 직원이 자연어로 분석** |

### 조직 문화 변화

- **데이터 기반 의사결정**: 회의 중에 "잠깐, 데이터 확인해볼게요" → 즉석 조회/시각화 가능
- **지식 관리 효율화**: 여기저기 흩어진 문서/매뉴얼을 하나의 채널에서 통합 검색
- **보안과 활용의 균형**: 개인정보는 자동으로 보호하면서 데이터는 적극 활용
